Цель: подготовить студента к устной защите по $ARGUMENTS (если пусто - по текущей рабочей папке).
Прочитай решение в папке. Задай по одному 7-10 вопросов, которые реально может задать ассистент: «почему так», «что будет если», «где слабое место».
После каждого ответа студента коротко оцени и дополни. В конце обнови DEFENSE.md: вопросы, хорошие ответы, что повторить.
