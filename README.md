# Учебный штаб ЦУ

Локальный инструмент поверх LMS Центрального университета, силлабусов и Яндекс Календаря:
канбан задач, расчёт оценки по формуле каждого курса, вердикты «идти на пару или нет»,
советы по late days и рабочие папки под задачи для Claude Code.

## Быстрый старт

```bash
bun install
bun link            # глобальная команда `cu` (bin в package.json)
cu login            # откроется окно Chromium: войди в LMS руками, окно закроется само
cu today            # дайджест в терминале
cu serve            # доска на http://localhost:4321
```

Автозапуск (демон: доска, синхронизация каждые 30 минут, напоминания, утренний дайджест):

```bash
cu install
```

Если `bun link` падает с `AccessDenied` (папка `~/.bun/install` принадлежит root), хватит ссылки:
`ln -sf ~/Projects/cu-study-hub/src/cli.ts ~/.bun/bin/cu`. Наш `cu` перекрывает системный `/usr/bin/cu`,
потому что `~/.bun/bin` стоит в PATH раньше. Внутри папки проекта по-прежнему работает `bun cu ...`.

## Команды

| Команда | Что делает |
|---|---|
| `bun cu login` | Вход в LMS в отдельном профиле браузера (`~/.cu-hub/browser-profile`). Пароль нигде не сохраняется |
| `bun cu sync` | LMS + календарь + проверка силлабусов на изменения |
| `bun cu today` / `week` | Дайджест дня / план недели |
| `bun cu course [курс]` | Баллы, блокеры, расхождения LMS и силлабуса |
| `bun cu do <задача>` | Рабочая папка `~/study/<курс>/<задача>` с BRIEF.md, MATERIALS.md, CLAUDE.md |
| `bun cu serve` | Веб-доска и фоновые задачи |
| `bun cu calendars` | Список календарей CalDAV |

## Claude Code

В проекте лежит `.mcp.json` с MCP-сервером `cu-hub` и команды:
`/today`, `/week`, `/course <курс>`, `/do <задача>`, `/defend`, `/after <что было на паре>`.

Каждая рабочая папка задачи тоже содержит `.mcp.json`, `/do` и `/defend`, поэтому `cd <папка> && claude`
сразу видит контекст. Чтобы `cu-hub` был доступен из любой папки:

```bash
claude mcp add --scope user cu-hub -- bun ~/Projects/cu-study-hub/src/mcp/server.ts
```

Инструменты MCP: `sync`, `today`, `week_plan`, `course_grades`, `grades_whatif`, `board_get`, `card_move`,
`card_add`, `card_note`, `classes`, `attendance_mark`, `late_days_advice`, `task_context`, `workspace_create`, `recoverable`.

## Материалы курса и агенты

**Зеркало курса** `~/study/<курс>/_course/` обновляется при синхронизации (не чаще раза в 6 часов), кнопкой
«⟳ Обновить материалы» на странице курса или `cu materials [курс]`:

- `README.md`: оглавление по неделям, ссылки (LMS, силлабус, TiMe, свои), политика ИИ;
- `NN-<неделя>.md`: все лонгриды недели, задания с дедлайнами и путями к вложениям;
- `attachments/<неделя>/`: лекции, презентации, условия заданий (скачиваются только новые версии);
- `SYLLABUS.md`: копия силлабуса; `repo/`: репозиторий курса, если есть доступ к git.culab.ru.

Свои файлы курса, которые синхронизация не трогает:

- `~/study/<курс>/COURSE_NOTES.md`: твои правила для агентов по курсу (стиль, рамки по неделям, git, защита),
  агент читает их в каждой задаче, они важнее общих инструкций;
- `~/study/<курс>/HISTORY.md`: оглавление прошлых работ с оценками, образец формата;
- `~/study/_templates/`: общие шаблоны ЦУ (шаблон презентаций для упаковки проектов).

`~/study/<курс>/` сам по себе проект Claude Code (CLAUDE.md и `.mcp.json`): «💬 Чат по курсу» открывается там.
Рабочая папка задачи лежит рядом и ссылается на `../_course`, так что агент видит весь курс.

**На карточке задачи:**

- «✨ Черновик агентом» запускает `claude -p` в рабочей папке в фоне. Режим берётся из политики ИИ курса:
  черновик + DEFENSE.md, черновик + EXPLAIN.md + DEFENSE.md или только PLAN.md (если ИИ нельзя генерировать решение).
  Когда агент закончит, придёт уведомление, итог виден на карточке, а сессию можно продолжить в терминале.
- «💬 Открыть в Claude» открывает новую сессию Code в приложении Claude в папке задачи
  (`claude://code/new?folder=…&q=…`), «⌨️ В терминале» открывает Terminal.app с `claude`.

Из CLI: `cu draft <задача>`, `cu chat <задача> [--terminal]`. Инструменты фонового агента без подтверждения:
чтение и запись файлов, MCP cu-hub, сборка и запуск (java, mvn, gradle, python, node). Список меняется в
`~/.cu-hub/config.yaml` → `agent.allowedTools`.

## Учебный план

Вкладка «🗺️ Учебный план»: календарь на месяц и на учебный год (сентябрь–август), листается стрелками.

- **Номер недели** считается от понедельника 1-й учебной недели (`rules/_academic.yaml`, можно поменять в настройках)
  и виден в заголовке «Недели», в боковом меню, в дайджесте и в календаре (Н1…Н15).
- **Академический календарь** (`rules/_academic.yaml`): зачётная неделя, сессия, каникулы, практика, пересдачи.
  Источник: хендбук, «График учебного процесса [2026–2027]», Школа технологий, 3 курс.
- **Контрольные точки курсов** (`plan:` в `rules/*.yaml`): проекты, контрольные, экзамены по неделям из
  силлабусов и «Графика контрольных работ». Показаны пунктиром со знаком ≈. Когда в LMS появляется работа
  с точной датой в ту же неделю, примерная отметка скрывается.
- **Свои промежутки**: выдели дни мышкой или нажми «+ Отметить промежуток».

MCP: инструмент `study_plan`.

## Настройки

Страница «⚙️ Настройки» на доске. Всё сохраняется в `~/.cu-hub/config.yaml` поверх `rules/*.yaml`:

- **Календарь**: логин Яндекса, пароль приложения (уходит сразу в Keychain, в файл не пишется),
  проверка подключения и выбор календарей. Пароль приложения: Яндекс ID → Безопасность →
  Пароли приложений → «Календарь CalDAV».
- **Напоминания**: время дайджеста, за сколько минут напоминать о паре, ревью недели,
  частота синхронизации, папка для рабочих папок задач.

Курс настраивается на своей странице, прямо как в Notion: название в заголовке и тег редактируются
на месте, цвет выбирается в свойствах, «✎ Изменить» у ссылок открывает силлабус, TiMe и свои материалы
(репозиторий, диск, записи), «В календаре» добавляет шаблоны названий пар. «Сбросить всё по курсу»
возвращает значения из `rules/*.yaml`.

Файл можно править и руками:

```yaml
caldav:
  url: https://caldav.yandex.ru
  username: login@yandex.ru
  keychainService: cu-hub-caldav
  calendars: []          # пусто = все
courses:
  "1118":                # id курса в LMS
    short: Джава
    links:
      - { label: Репозиторий, url: https://git.culab.ru/... }
```

## Правила курсов

`rules/<курс>.yaml`: веса и плановое число работ по силлабусу, блокеры, late days, политика ИИ,
шаблоны календаря и задачи подготовки. Движок считает оценку так же, как LMS:
по каждой активности `Σ баллов / плановое число работ × вес`. Если веса в LMS и силлабусе
расходятся, считается по LMS, а расхождение показывается на доске.

Режимы политики ИИ (`ai_policy.mode`) попадают в CLAUDE.md рабочей папки:

- `execute`: агент делает черновик и готовит конспект к защите;
- `assist`: работа вместе, с объяснением каждого шага;
- `tutor_only`: агент не пишет решение, только план, вопросы и проверка.

## Данные

Всё лежит в `~/.cu-hub/`: `hub.sqlite`, `cookies.json` (права 600), `browser-profile/`, `digest.md`, `daemon.log`.
Инструмент только читает LMS. Сдавать работы и переносить дедлайны на late days ты делаешь сам.
