# Правила курсов

Один файл = один курс LMS. Откуда берутся файлы:

- `rules/*.yaml` в репозитории: курсы, разобранные по силлабусу (веса, блокеры, контрольные точки).
  Если твой курс тут есть, мастер настройки возьмёт его как есть.
- `~/.cu-hub/rules/*.yaml`: курсы, которые мастер создал сам из данных LMS. Файл с тем же `lms_id`
  здесь важнее файла из репозитория, так что править можно свою копию.

Какие курсы видны на доске, решает шаг «Курсы» в мастере (`cu setup`), список хранится в
`~/.cu-hub/config.yaml` → `trackedCourses`. Id курсов: `cu courses`.

## Что дописать по силлабусу

Мастер знает из LMS только веса активностей, число работ и late days. Остальное есть только в силлабусе:

| Поле | Что это | Пример |
|---|---|---|
| `blockers` | условия допуска и сдачи: без них курс не закрыть | `- { label: "Экзамен ≥ 3.5", activity: exam, min: 3.5 }` |
| `pass_threshold` | минимальная итоговая оценка (по умолчанию 3.5) | `3.5` |
| `assessment` | форма контроля | `экзамен` / `зачёт` |
| `activities[].kind` | тип активности, мастер угадывает по названию | `homework`, `test`, `project`, `exam`, `seminar`, `attendance`, `bonus` |
| `activities[].effort_h` | сколько часов уходит на одну работу: для плана недели | `6` |
| `calendar.match` | регулярки по названию пары в календаре | `["java"]` |
| `calendar.kinds` | типы пар и какие активности на них оцениваются | см. `compnet.yaml` |
| `prep` | что сделать перед парой, попадёт на доску | `- { before: seminar, title: "Прочитать материалы", effort_h: 0.5 }` |
| `plan` | контрольные точки по неделям из «Графика контрольных работ» | `- { title: "Контрольная 1", kind: test, week: 6 }` |

Блокеры: `activity` = `key` активности. `min` = порог оценки за работу, `match` = часть названия
конкретной работы, `count` = сколько работ нужно, `all_submitted: true` = сдать всё.

`plan`: `week: 6` (неделя), `weeks: [13, 15]` (диапазон) или `period: session` / `credit` (из `_academic.yaml`).

Готовые примеры: `java-dev.yaml` (экзамен + блокеры), `compnet.yaml` (защиты на семинарах),
`black-mirror.yaml` (зачёт по посещениям).

## Академический календарь

`_academic.yaml`: начало семестра, сессия, каникулы для 2026/27, Школа технологий, 3 курс. Если у тебя
другой график, скопируй файл в `~/.cu-hub/rules/_academic.yaml` и поправь: он важнее файла из репозитория.
Начало семестра можно поменять и в мастере или настройках.
